# SpaceMission Lab

**Виртуальная лаборатория орбитальных перелётов**

Учебное приложение для моделирования идеального перелёта Хомана между двумя круговыми
компланарными орбитами Земли и расчёта необходимого топлива по уравнению Циолковского.

> **Важно.** Это образовательная орбитальная модель. Она не является программным
> обеспечением для оперативного планирования космических полётов.

## Возможности

- Расчёт перелёта Хомана: импульсы со знаком и направлением, суммарная Δv, время перелёта,
  периоды начальной и целевой орбит. Поддерживаются подъём и снижение орбиты; при равных
  высотах сообщается, что перелёт не требуется.
- Бюджет топлива: доступная Δv, минимальное топливо для сухого аппарата, расход при
  введённой заправке, остаток и запас Δv, явная пометка невыполнимого бюджета.
- Схема орбит в Plotly с равным масштабом осей: Земля, начальная и целевая орбиты,
  перелётный эллипс, пройденная половина, точки манёвров. Ползунок прогресса ставит аппарат
  по прошедшему времени через уравнение Кеплера.
- Сравнение «Базового» и «Изменённого» сценариев и график минимальной потребности в топливе.
- Демонстрационные пресеты (только входные данные).
- Воспроизводимые параметрические эксперименты с экспортом в CSV.
- Экспорт: конфигурация (JSON), результаты (CSV, UTF-8 с BOM), автономный HTML-отчёт.
  Импорт JSON со строгой проверкой.

## Установка и запуск

Требуется Python 3.11 или новее.

### Windows (PowerShell)

```powershell
cd SpaceMissionLab
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Если PowerShell запрещает запуск скриптов, выполните один раз
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или активируйте окружение из
командной строки `cmd`: `.venv\Scripts\activate.bat`.

### macOS / Linux

```bash
cd SpaceMissionLab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

### Тесты

```bash
python -m pytest -q
```

Тесты не требуют сети.

## Модель

### Константы (СИ)

| Константа | Значение | Источник |
|---|---|---|
| Гравитационный параметр Земли μ | 3.986004418·10¹⁴ м³/с² | WGS 84 (NGA), IERS Numerical Standards |
| Опорный радиус Земли R⊕ | 6 371 000 м | Округлённый средний радиус (IUGG R3 = 6 371 000.79 м) |
| Стандартное ускорение g0 | 9.80665 м/с² (точно) | CODATA 2022 / NIST |

Земля рассматривается как сферическая точечная масса. Опорный радиус используется только
для перевода высоты над поверхностью в расстояние от центра: r = R⊕ + h. Экваториальный
радиус WGS 84 (6 378 137 м) больше на ~7 км, поэтому высоты в модели условны.

### Уравнения

- Круговая скорость: v = √(μ / r)
- Большая полуось перелётного эллипса: a = (r1 + r2) / 2
- Вис-вива: v = √(μ (2/r − 1/a))
- Импульсы: Δv1 = vt1 − v1, Δv2 = v2 − vt2, Δv = |Δv1| + |Δv2|
- Время перелёта: t = π √(a³ / μ)
- Период круговой орбиты: T = 2π √(r³ / μ)
- Доступная Δv: Δv_дост = Isp · g0 · ln(m0 / m_сух)
- Конечная масса: m_f = m0 · exp(−Δv / (Isp · g0))
- Минимальное топливо: m_сух · (exp(Δv / (Isp · g0)) − 1)
- Уравнение Кеплера: M = E − e·sin E (решается методом Ньютона с защитной бисекцией и
  ограничением числа итераций)

### Пресеты

| Пресет | h1, км | h2, км | m_сух, кг | m_т, кг | Isp, с |
|---|---|---|---|---|---|
| Низкая орбита: 400 → 800 км | 400 | 800 | 500 | 150 | 300 |
| Высокая орбита: 400 → 35 786 км | 400 | 35 786 | 1 500 | 4 000 | 320 |
| Снижение орбиты: 1 000 → 400 км | 1 000 | 400 | 500 | 100 | 300 |

Пресеты не воспроизводят реальные миссии. Высота 35 786 км сама по себе не делает орбиту
геостационарной: нужны также нулевое наклонение и период, равный звёздным суткам.

### Исследовательский эксперимент

Гипотеза: «Расчётная модель позволяет исследовать влияние высоты целевой орбиты и удельного
импульса на параметры идеального орбитального перелёта.»

1. Начальная орбита 400 км; целевая высота 500–50 000 км, 100 равномерных точек;
   сухая масса 1 000 кг; Isp 320 с. Рассчитываются Δv, время перелёта, минимальное топливо.
2. (Дополнительно) Перелёт фиксирован (по умолчанию 400 → 35 786 км), Isp 200–4 500 с,
   60 точек. Рассчитывается минимальное топливо.

Показатели с разными единицами отображаются на отдельных графиках. Все значения получены
расчётом; реальная телеметрия, опросы или лётные данные не используются.

## Ограничения

Модель не учитывает:

- атмосферное сопротивление;
- несферичность гравитационного поля Земли;
- возмущения от третьих тел (Луна, Солнце);
- изменение плоскости орбиты;
- конечную длительность работы двигателя (импульсное приближение может не подходить для
  двигателей малой тяги);
- ошибки навигации;
- резервы топлива на другие операции.

Перелёт Хомана выводит аппарат на целевую орбиту, но не обеспечивает встречу с другим
аппаратом. Он не является оптимальным среди всех возможных стратегий перелёта. Выполнимость
по топливу не означает выполнимости миссии в целом. Оперативное планирование требует
существенно более детальных моделей и их независимой проверки.
